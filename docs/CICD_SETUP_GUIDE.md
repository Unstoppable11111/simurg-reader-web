# Simurg Reader Web CI/CD 自动化部署配置指南

本文档指导如何在 Gitee 上配合宝塔服务器实现代码提交后的全自动构建、平滑部署与秒级回滚。

---

## 1. 架构特点与核心优势

1. **服务器零性能损耗**：Nuxt SSR 编译全在 Gitee 云端完成，宝塔 4GB 内存服务器不受任何高负载影响。
2. **零停机平滑更新 (Zero-Downtime)**：基于 PM2 Cluster 模式，重载期间轮流更新子进程，线上用户无感知。
3. **版本快照与极速回滚**：每次部署前自动对现有运行目录进行带时间戳的快照备份，出现异常可一键回滚。

---

## 2. Gitee 端配置步骤（仅需配置一次，约 2 分钟）

### 步骤一：添加 SSH 服务器凭证
1. 打开 Gitee 仓库主页：`https://gitee.com/tireba/simurg-reader-web`。
2. 进入 **【管理】** -> 展开左侧菜单 **【Gitee Go】** -> 点击 **【凭证管理】**（或【主机组管理】）。
3. 点击 **【新建凭证】**：
   - **凭证类型**：选择 `SSH 主机凭证`（或 `账号密码 / SSH 私钥`）。
   - **凭证名称**：填入 `SSH_SERVER`（对应流水线配置文件中的变量名）。
   - **主机地址**：填入您宝塔服务器的公网 IP。
   - **SSH 端口**：填入服务器 SSH 端口（默认通常是 `22`）。
   - **认证方式**：填入服务器登录用户名（如 `root`）和登录密码（或导入公钥对应的私钥）。
4. 保存凭证。

---

### 步骤二：配置生产环境变量（可选）
1. 在 Gitee 仓库中点击 **【管理】** -> **【Gitee Go】** -> **【环境变量】**。
2. 添加变量：
   - 变量名：`NUXT_PUBLIC_API_BASE`
   - 变量值：`http://www.sr-web-test.tata.org.cn:8082/api`（或生产环境实际 API 基础地址）。
3. 如果未配置该变量，流水线会自动使用默认配置。

---

## 3. 日常使用方式

### 自动触发上线
- 只要在本地代码修改完成后推送到指定分支（`master` 或 `feature-1.0`）：
  ```bash
  git push origin master
  ```
- Gitee 会自动触发流水线运行：
  1. 在云端安装依赖并打包为 `.output.tar.gz`。
  2. 自动上传至服务器 `/www/wwwroot/simurg-reader-web/`。
  3. 执行备份、解压并平滑重载 PM2。

---

## 4. 应急情况：如何秒级回滚？

若某次上线后发现严重业务缺陷，无需重新编译，直接在宝塔终端执行回滚脚本：

```bash
cd /www/wwwroot/simurg-reader-web
bash scripts/rollback.sh
```

脚本会自动检测 `backups/` 目录中的上一个稳定版本并瞬间复原，5 秒内恢复线上访问。
